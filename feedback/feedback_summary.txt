[ 피드백 1 ] 색상

  문제
    - 현재 베이지(#ebe6d9) + 테라코타(#c86f50) 조합이 오래된 해외 블로그 느낌
    - 생동감이 부족하고 따분한 인상

  개선 방향
    - "무채색 + 포인트색" 조합으로 교체
      예) 블랙/그레이/화이트 배경 + 쨍한 파랑, 오렌지, 네이버그린 중 하나
    - 사용 색상은 3가지 이내로 제한: 무채색 2종 + 포인트 1색
    - 내용이 적어 빈 공간이 많다고 느껴지면 다크모드(어두운 배경) 고려
    - 핀터레스트에서 포폴/컬러 조합 검색 후 색 코드 추출해서 쓰는 것도 방법

  코드 영향 파일
    - src/styles/index.css (CSS 변수 전체 교체)


[ 피드백 2 ] 폰트

  문제
    - 폰트 패밀리 미지정 → 브라우저 기본값 사용, 괄호·글자 정렬 어긋남
    - 전반적인 본문 폰트가 13~15px 수준으로 작아서 옛날 PC 전용 사이트처럼 보임
    - 자간(letter-spacing)이 거의 없음

  개선 방향
    - 폰트: Pretendard 적용 (무료, 한글+영문 호환 우수, 굵기 다양)
      CDN: https://cdn.jsdelivr.net/gh/orioncactus/pretendard/dist/web/static/pretendard.css
    - 기본 본문 폰트 최소 14~16px 이상으로 상향 (현재 0.8125rem → 1rem 이상 권장)
    - 행간: 1.3~1.8 (긴 글은 넓게)
    - 자간: 한글 -0.02~-0.05em 정도 좁히기 (영문은 -0.01~-0.02em)

  코드 수정 포인트
    - index.css: font-family 전역 설정 추가
    - hero.css: bio-text, section-label 폰트 크기 상향
    - projects.css: project-desc, feature-detail-body 폰트 크기 상향
    - 현재 section-label(0.6875rem / 11px)은 너무 작음 → 0.75rem(12px) 이상으로


[ 피드백 3 ] 요소들 위계

  문제
    - 요소들의 크기·굵기 차이가 작아서 위계가 불명확
    - 데스크탑의 Projects feature-panel에서:
        왼쪽 리스트 항목 타이틀(0.875rem, text-medium) <
        오른쪽 패널 제목(text-sm, font-semibold)
      → 오른쪽 박스가 왼쪽보다 강조되어 있어서
        "왼쪽 리스트를 클릭하면 오른쪽에 설명이 나온다"는 관계가 직관적으로 인식되지 않음
      → 피드백에서 "우연히 클릭했다가 알았다"고 언급됨

  개선 방향
    a) feature-panel 레이아웃 변경 검토
       - 현재 구조(좌측 리스트 + 우측 패널) 대신,
         클릭 시 해당 항목 아래로 아코디언 확장 방식으로 통일 (모바일처럼)
         또는 자동 재생으로 순서대로 설명이 열리는 방식
       - 변경 시 feature-detail-inline(모바일 아코디언)만 남기고
         feature-detail-panel(데스크탑 사이드패널) 제거 가능

    b) 폰트 크기·굵기 위계 명확화
       - 대제목: 24~28px, Bold 또는 ExtraBold
       - 소제목/항목명: 18~20px, SemiBold
       - 본문/설명: 14~16px, Regular
       - 보조 텍스트: 12~13px, Regular (최소 한계)
       - 강조 시 Medium이 아닌 SemiBold 이상 사용

  코드 영향 파일
    - src/components/sections/Projects.tsx (feature-panel 구조 변경)
    - src/styles/components/projects.css (크기 조정)


[ 피드백 4 ] 콘텐츠 그룹핑

  문제
    - Experience 섹션 내용이 적음

  개선 방향

    - 통합 섹션 구성 예시:
        프로필(사진/이름/소개글)
        기술 스택
        경력/자격증/교육

  코드 영향 파일

    - src/data/portfolio.ts (navigation 수정)

[ 피드백 5 ] 프로젝트 섹션

  문제
    - 프로젝트가 2개뿐인데 카드가 너무 작고 빽빽해서 볼륨이 없어 보임
    - 현재 project-logo: 3.25rem (52px) 정도로 작은 편
    - 여백과 공간이 너무 "정직"하고 콤팩트함

  개선 방향
    - 프로젝트 1개당 차지하는 면적을 더 넓게
    - 여백(padding/margin) 확대, 섹션 내부 간격 상향
    - 프로젝트 로고/이미지 크기 키우기
    - 가로 전체 행을 활용 (현재 max-w-5xl 중심으로만 사용)
    - 기본 폰트가 커지면 자동으로 볼륨감이 생기는 부분도 있음 (피드백2 연동)
    - 참고: 지디웹 IT/솔루션 수상작 포폴 레이아웃

  코드 영향 파일
    - src/styles/components/projects.css (padding, 이미지 크기, 간격 등)


[ 피드백 6 ] 메인 비주얼 / 컨셉 부재

  문제
    - 현재 Hero 영역이 프로필 사진 + 이름 + 소개글로만 구성
    - 컨셉 없이 정보를 나열한 형태 → 심심하고 인상이 약함

  개선 방향
    a) 컨셉 설정
       - 코드 에디터 스타일 (IDE 느낌)
       - 터미널/CLI 스타일
       - 아이폰/맥북 폴더 오마주
       - 그 외 본인이 좋아하는 것을 중심으로 한 컨셉

    b) 메인 비주얼 기본 구성
       - 비주얼(이미지/일러스트/아이콘 등) + 메인 타이틀 + 서브 타이틀
       - 이미지는 ChatGPT로 배경 없는 PNG 생성 가능
       - 개발 아이콘, 코드 창, 좋아하는 게임 캐릭터 등 "나를 표현하는 요소"

    c) 방향성 선택지
       - 디자인 유려함을 강조 (프론트엔드 강점)
       - 인터랙티브 효과 강조 (스크롤 애니메이션, 마우스 반응 효과 등)

    참고 링크 (피드백 파일에서 제공됨)
       - 지디웹: https://www.gdweb.co.kr/
       - 인터랙티브 개발자 포폴 유튜브: https://www.youtube.com/watch?v=cpEeqACsF_Q

  코드 영향 파일
    - src/components/sections/Hero.tsx (레이아웃 전면 재설계)
    - src/styles/components/hero.css
